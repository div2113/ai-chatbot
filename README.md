# AI Chatbot

## 📌 Project Overview

This project is a local AI chatbot built using FastAPI and Ollama.

The goal of this project is not only to build a chatbot but also to understand the backend concepts behind it step by step.

## 🛠️ Technologies

- Python
- FastAPI
- Git
- Ollama (coming soon)

## 📚 Learning Goals

- Understand Python backend development
- Learn Git and GitHub professionally
- Build REST APIs
- Integrate a local Large Language Model (LLM)
- Follow software engineering best practices
